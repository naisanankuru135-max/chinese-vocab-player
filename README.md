# 🇨🇳 中国語 単語帳 音声プレイヤー 🇯🇵

ネイティブ音声合成による正確な四声（ピンイン）と日本語訳の自動読み上げ聞き流しツール。

## 🌐 公開Webサイト（誰でもブラウザですぐ使えます）
👉 **[https://naisanankuru135-max.github.io/chinese-vocab-player/](https://naisanankuru135-max.github.io/chinese-vocab-player/)**

### 搭載機能
- #78 〜 #81 の単語・ピンイン・日本語訳
- 中国語のあとに日本語訳を自動読み上げ（聞き流しシャドーイング対応）
- 2色切り替えハイライト（中国語: 青 / 日本語: 緑）
- 速度調整、間隔調整、リピート回数設定
- 暗記テスト用マスク機能
- 新規単語の一括追加
